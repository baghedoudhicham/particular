# Design Module

Use DESIGN to turn a chosen strategy into a resolved visual system and screens.

## Order of operations

1. composition
2. content hierarchy
3. typography
4. imagery
5. brand-derived devices
6. component behavior
7. interaction
8. responsive recomposition
9. accessibility
10. polish

## Composition

Define grid, alignment datums, dominant elements, whitespace, image behavior, reading path, section rhythm, and transitions before cards/components.

Translate adjectives into geometry. Specify columns, spans, margins, gutters, type measures, image ratios, crop behavior, overlap, and responsive transforms.

## System quality

Use components for behavior and consistency, not to flatten every section into the same visual container.

## Validation

Run the transplant test, 3/10/30-second test, AI/category-slop checks, and realistic-size desktop/tablet/mobile inspection before approval.
