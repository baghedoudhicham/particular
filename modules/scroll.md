# Scroll Module

Use SCROLL only when motion materially improves comprehension or brand expression.

## Gate

Ask:

- Does chronology matter?
- Does spatial transformation explain something?
- Does progressive reveal improve comprehension?
- Is there meaningful visual material?
- Can the experience remain usable without motion?

If the answer is mostly no, do not build immersive scroll.

## When justified

Define:

- entry state
- scroll progression
- pinned/fixed behavior
- transitions
- exit state
- mobile alternative
- reduced-motion alternative
- loading/performance budget

## Static quality rule

Every key scroll state should still look intentionally designed as a static frame.

Motion cannot compensate for weak typography, hierarchy, imagery, or composition.
