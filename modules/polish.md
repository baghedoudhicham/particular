# Polish Module

Use POLISH when the direction is already correct and should not be reconceived.

## Freeze first

Identify and preserve:

- successful IA
- successful composition
- successful brand devices
- successful imagery
- successful interaction patterns

## Polish targets

Refine:

- type scale and line breaks
- spacing rhythm
- alignment and optical balance
- image crop/focal point
- icon consistency
- button/control states
- responsive edge cases
- contrast/focus
- micro-interactions
- content density
- implementation fidelity

## Rule

Do not turn polish into concept generation.

If the architecture is right, improve resolution locally.
