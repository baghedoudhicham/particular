# Concept Module

Use CONCEPT when the strategy is stable but the visual/compositional direction is not.

## Before concepting

Lock:

- source hierarchy
- factual truth
- preference truth
- visual category
- audience and conversion goal
- design thesis
- calibration
- anti-DNA

## Generate directions

Each concept must differ meaningfully in:

- composition
- image behavior
- type relationship
- density/rhythm
- brand device
- interaction philosophy

Do not produce cosmetic variants of the same layout.

## For each direction state

- concept name
- one-sentence thesis
- why it fits the client/category
- defining geometry
- image strategy
- type strategy
- interaction behavior
- risk
- what it intentionally does not do

## Selection rule

Prefer the direction that best balances client desirability, brand specificity, category fit, clarity, and implementation credibility — not the one with the most novelty.
