# Redesign Module

Use REDESIGN when a product already exists and the goal is improvement rather than reinvention.

## Workflow

1. audit before changing
2. identify what already works
3. freeze strong decisions
4. rank problems by impact
5. fix hierarchy before decoration
6. fix composition before components
7. fix typography before effects
8. fix UX before animation
9. polish only after structure works

## Scope control

Classify every issue as:

- MICRO
- LOCAL
- SECTION
- SYSTEMIC

Apply the smallest intervention capable of solving the problem.

Do not globally regenerate the product because one section is weak.

## Preserve context

Respect current users, content models, implementation constraints, analytics continuity, accessibility, and operational workflows.
