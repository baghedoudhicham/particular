# DNA Module

Use DNA to convert brand assets, references, client feedback, and category evidence into an explicit design model.

## Extract

### Brand DNA
Logo geometry, palette, typography, image language, materials, forms, voice, product/physical signals.

### Reference DNA
Grid, spacing, type scale, image dominance, crop, dark/light balance, borders, radius, cards, icons, CTA prominence, rhythm, motion, interaction, composition archetypes.

### Client DNA
Selected, rated, rejected, criticized, requested, and unchanged visual decisions.

### Category DNA
Signals that create trust/recognition, clichés, conventions worth preserving, conventions worth elevating.

### Project DNA
Brand- or product-derived devices that would not make sense for an unrelated organization.

### Anti-DNA
Explicitly wrong visual categories, claims, motifs, content patterns, and interactions.

## Calibration

Infer design axes from evidence. Do not guess aesthetic intensity from a few adjectives.

## Output

Produce both a concise human-readable rationale and a portable machine-readable Project DNA artifact.
