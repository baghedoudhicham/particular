# Methodology

## 1. Intake

Collect the brief, authoritative factual sources, brand assets, existing product, reference URLs/screenshots, audience, business objective, implementation constraints, and any client feedback or ratings.

## 2. Classify truth

Separate factual truth from preference truth. Mark ambiguous content explicitly; never let a design placeholder become a business claim.

## 3. Extract DNA

Build Brand DNA, Reference DNA, Client DNA, Category DNA, Project DNA, and Anti-DNA.

## 4. Calibrate

Set evidence-backed design axes such as brand expression, novelty, density, typographic expression, image dominance, CTA prominence, motion, and technicality.

## 5. Name the visual category

State what kind of experience the stakeholder is actually buying. Improve that category before trying to replace it with a more fashionable one.

## 6. Define strategy

Establish audience, primary conversion, 3/10/30-second comprehension goals, design thesis, IA, content hierarchy, and proof model.

## 7. Compose

Define grid, dominant element, alignment datums, scale, density, imagery, section rhythm, and transitions before components.

## 8. Build the visual system

Resolve typography, imagery, icons, brand-derived devices, components, interaction budget, and responsive recomposition.

## 9. Build with constraints

Define implementation contract, dynamic-content behavior, accessibility, performance, search/discoverability, analytics, and CMS/data requirements.

## 10. Critique adversarially

Run client, user, brand, and engineering critics. Pass the quality gates and inspect at realistic zoom on desktop, tablet, and mobile.

## 11. Iterate locally

Classify feedback and make the smallest effective intervention. Freeze what already works.

## 12. Learn from outcomes

When selection data appears, update Client DNA and run a delta analysis without rewriting the lesson to defend the previous concept.
