# Design Calibration

Calibration makes aesthetic intensity explicit before generation.

Infer 1–10 values from evidence, not personal preference:

- Brand Expression
- Visual Novelty
- Layout Variance
- Visual Density
- Information Density
- Typographic Expression
- Image Dominance
- Editoriality
- Technicality
- Materiality
- Ornamentation
- CTA Prominence
- Interaction Complexity
- Motion Intensity
- 3D / Immersive Intensity

Also position the project on:

- Rectilinear ↔ Organic
- Quiet ↔ Expressive
- Institutional ↔ Human
- Utility ↔ Editorial
- Precise ↔ Playful
- Minimal ↔ Layered

## Example

```yaml
brand_expression: 8
visual_novelty: 5
layout_variance: 6
visual_density: 5
information_density: 5
typographic_expression: 7
image_dominance: 8
editoriality: 4
technicality: 6
materiality: 5
ornamentation: 4
cta_prominence: 7
interaction_complexity: 4
motion_intensity: 3
immersive_intensity: 1
```

Calibration is not a scoring game. It is a shared contract between evidence and execution.
