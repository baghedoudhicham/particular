# Evidence Model

Particular separates **what is true** from **what is preferred**.

## Factual truth

Classify each meaningful fact:

| Status | Meaning |
| --- | --- |
| LOCKED | explicit requirement |
| VERIFIED | supported by authoritative evidence |
| CLIENT-SUPPLIED | supplied directly, not independently verified |
| INTERPRETABLE | direction exists with execution freedom |
| UNDEFINED | no reliable information |
| PROPOSED | recommendation |
| PLACEHOLDER | temporary design need |

Never present proposed or placeholder content as verified business truth.

## Preference truth

Use observed stakeholder behavior to resolve subjective visual ambiguity.

Priority:

1. selected designs
2. highly rated designs
3. client-supplied visual references
4. brand assets
5. current identity
6. category conventions
7. written aesthetic preferences
8. abstract adjectives
9. designer interpretation

Preference truth never overrides factual accuracy.

## Evidence weighting

Score sources 1–5 on:

- Authority
- Relevance
- Recency
- Specificity
- Preference Signal

Do not turn this into fake mathematical certainty. The score is a discipline for making assumptions visible and resolving conflicts.

## DNA layers

### Brand DNA
Logo, type, palette, physical forms, imagery, material, voice, product geometry, cultural/historical signals.

### Reference DNA
Grid, type scale, density, image ratio, color distribution, border/radius/depth, CTA prominence, components, navigation, rhythm, motion, and composition archetypes.

### Client DNA
Chosen, rated, rejected, criticized, requested, and untouched decisions.

### Category DNA
Recognition/trust conventions, tired conventions, and category expectations worth elevating or retaining.

### Project DNA
Specific devices or behaviors justified only by the target organization/product.

### Anti-DNA
Explicit wrong categories, tropes, behaviors, claims, and aesthetics.
